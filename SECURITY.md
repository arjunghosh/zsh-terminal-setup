# Security Policy

This project ships shell configuration and, from v0.1.0, scripts that modify files in your home directory. If you find a vulnerability (for example, a script that writes outside the files it documents, executes unpinned remote code, or leaks data), please **do not open a public issue**. Report it privately via [GitHub's private vulnerability reporting](https://github.com/arjunghosh/zsh-terminal-setup/security/advisories/new). Expect an acknowledgement within 7 days. Only the latest release is supported.
